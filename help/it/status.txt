GIT-SHARED-STATUS(1)

NOME
    git shared status - mostra lo stato di ogni file shared

SINTASSI
    git shared status [--peers]

DESCRIZIONE
    Mostra ogni file shared con path, ID, stato e cosa fare. Gli stati
    sono scritti in inglese, come li stampa il comando:

    aligned               hai l'ultima versione: niente da fare
    new version to apply  un peer ne ha pubblicata una nuova: update
    applied, to commit    update l'ha applicata: commit
    to publish            l'hai modificato sull'ultima versione: publish
    diverged              l'hai modificato su una versione vecchia, o due
                          peer hanno pubblicato senza vedersi: update,
                          che unisce
    merge in progress     update ha trovato un conflitto: correggi il
                          file, git add, di nuovo update
    pending commit        set, link, unlink o mv non ancora committato:
                          commit, oppure restore di .gitshared per
                          annullare
    unlinked              dichiarato qui ma non collegato (un clone): link
    inconsistent          il file e' stato cancellato, o rinominato senza
                          'git shared mv', oppure .gitshared e' stato
                          modificato a mano, oppure nessun branch dichiara
                          piu' il file: mv <vecchio> <nuovo> per una
                          rinomina, unlink (con l'id, nell'ultimo caso),
                          oppure restore di .gitshared
    suspended on this branch (...)
                          questo branch non e' tra i branch del file: qui
                          e' un file normale. Lo stato vero e' tra
                          parentesi. 'git shared branch' lo cambia.
    suspended on this branch (not declared here)
                          questo branch non dichiara il file (e' nato
                          prima del set): la nota dice su quale branch e'
                          shared. Niente da fare.

    Prima status riceve le versioni annunciate dai peer: non scarica
    nulla se non c'e' niente di nuovo, e non tocca il working tree. Una
    nota dice quando una versione annunciata non si e' potuta ricevere,
    o quando la versione di un peer va unita: in entrambi i casi,
    update.

    Per un file pubblicato in remoto (prototipo) una riga "creator"
    mostra il repository da cui arrivano le versioni: status gli chiede
    se c'e' una versione nuova e scarica solo la catena delle versioni.
    Se non risponde lo dice una nota, e lo stato si ricava dalle versioni
    che ci sono gia'.

OPZIONI
    --peers
        Mostra anche, per ogni peer: stessa versione; versione piu'
        vecchia (publish); annunciata, non ancora ricevuta (niente da
        fare: la ricevera' da se'); versione piu' nuova o diversa
        (update --all); nessuna versione (publish); non condivide piu' il
        file, o non trovato (prune); non leggibile adesso. Dai peer non
        scarica e non cambia nulla.

VEDI ANCHE
    git shared update --help, git shared publish --help
